# Website

## Purpose

This website represents Avi Vajpeyi professionally.

It should communicate:

- current research
- publications
- software
- talks
- outreach
- teaching
- contact information

## Writing style

- Friendly but professional.
- Avoid marketing language.
- Prefer short paragraphs.
- Be technically accurate.

## Design philosophy

- Minimal
- Fast
- Accessible
- Mobile-first

Do not introduce unnecessary animations.

## Content

Research pages should emphasize:

- Bayesian inference
- gravitational-wave astronomy
- statistical methods
- open-source software

## Images

Prefer SVG where possible.

Compress large images.

## Before committing

Run

npm run lint
npm run build

Fix all warnings before committing.
