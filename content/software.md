## Skills in practice

- **Statistical modelling:** Bayesian inference for noise spectra, correlated signals and uncertainty, through [LogPSplinePSD](https://github.com/nz-gravity/LogPSplinePSD/).
- **Scientific Python and JAX:** reusable interfaces for data, transforms and inference, including [WDM window and subband implementations](https://github.com/pywavelet/wdm_transform/commit/b563b0c6fb0e9b217fcb4297a9183a5a82e05e0c).
- **Software validation:** reconstruction and gradient tests for transforms, and inference tests and sampler controls for spectral models. See the contribution links in each project.
- **Making methods usable:** configuration, posterior outputs, diagnostic plots, example notebooks and technical documentation. The [LogPSplinePSD case study](/project/logpsplinepsd/) follows one example from problem to interface.
